# Flow anomaly model

The shipped forest is trained on a **synthetic benchmark**, not on CIC or UNSW results. All reported numbers are generated by `train.py` on a held-out split. It has 16 trees with maximum depth 5. Six transformed flow features classify benign, scan, flood and exfiltration flows. Rule detectors cover attacks that are not identifiable from these features.

```bash
python3 -m venv .venv
.venv/bin/pip install -r ml/requirements.txt
.venv/bin/python ml/train.py
npm run test
```

Public datasets:

- CIC-IDS2017: https://www.unb.ca/cic/datasets/ids-2017.html — download the labeled MachineLearningCSV archive, extract a flow CSV, then run `.venv/bin/python ml/train.py --csv /path/to/Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv --dataset-name CIC-IDS2017`.
- UNSW-NB15: https://research.unsw.edu.au/projects/unsw-nb15-dataset — not automatically compatible; map its columns and labels to the six documented flow features before training.

Training performs preprocessing, stratified train/test split, evaluation, multiclass confusion matrix and per-class report. It exports `content/model.json`, `content/metrics.json` and `ml/parity-fixture.json`. TypeScript compares every class probability with Python for all 64 fixture rows; inputs are cast to float32 to match sklearn. The inference runtime does not depend on Python. Retraining updates the method page automatically.

The public dataset archives were not downloaded during this build. Metrics cannot establish real-world recall or false-positive rates. Validate on independent capture days and independent networks before operational use; monitor drift and tune thresholds. Feature contributions use one-feature median ablation, not SHAP or a causal explanation.
