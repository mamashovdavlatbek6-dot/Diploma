## Исправления при аудите

Статический TTF для next/og; отсутствие внешней загрузки декоративного символа; HTTP 404 без общей streaming-loading boundary; парсер агента разделяет файлы разных форматов; чтение EWMA-сигналов из State; корректное маскирование сжатых IPv6; реальные маркеры карты только из переданной страны; живые домашние счётчики; сохранение query при смене языка; ограничение DOM; очистка аналитики при отзыве согласия.

## Ограничения

Перезапуск serverless-экземпляра может потерять default state/outbox. Redis объединяет окна и статусы; Supabase — события/счётчики. Контактная очередь без канала не является worker с автоматическим повтором доставки. Прогресс анализа состоит из чтения файла и фаз нормализации/детекции, не является потоком каждой строки. Публичные GET раскрывают принятые данные: включите IP_MASKING до ingest личных журналов. Country-centroid geo anomaly является эвристикой, не доказательством компрометации.
