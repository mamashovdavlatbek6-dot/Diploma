# Offline attack fixtures

These files are intentionally generated demonstration inputs, not captured production traffic. The analyzer marks their input source as **File**, never live traffic. Rule-specific normalized JSON/NDJSON samples are generated by `scripts/generate-samples.ts` from the deterministic simulator. Dates are fixed at 2026-10-06 for reproducibility.

- `ssh-bruteforce.log`: Linux auth.log, 12 failures then success.
- `nginx-web.log`: combined access log, encoded XSS and scanner user agent.
- `cic-scan.csv`: CICFlowMeter CSV, 24 SYN-only destination ports.
- `zeek-scan.log`: Zeek TSV conn.log, 24 failed destination ports.
- `attacks/*.json`: each of the 11 rule/model attack classes.
- `generic.ndjson`: port scan in normalized NDJSON.

Never execute any string from a log. The sample XSS payload is data only.
